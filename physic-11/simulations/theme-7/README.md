# Physics Lab UA — §7

Інтерактивна лабораторія до теми «Електричний струм у газах».

Реалізовано:
- умови виникнення електричного струму в газах;
- модель йонізації атома електронним ударом;
- порівняння енергії електрона з енергією йонізації;
- умовну ВАХ газового розряду;
- несамостійний і самостійний розряд;
- анімацію руху електронів і позитивних йонів між електродами;
- електронну лавину;
- чотири види самостійних газових розрядів: іскровий, тліючий, дуговий, коронний;
- інтерактивну задачу на мінімальну швидкість електрона;
- тест із 7 запитань.

Для запуску відкрийте `index.html` у браузері.

- `app.js`
