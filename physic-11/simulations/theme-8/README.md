# Physics Lab UA — §8

Інтерактивна лабораторія до теми «Електричний струм у вакуумі. Електровакуумні прилади».

Реалізовано:
- поняття вакууму та роботи виходу;
- види електронної емісії;
- анімовану модель термоелектронної емісії;
- утворення електронної хмари над нагрітим металом;
- модель вакуумного діода;
- пряме та зворотне ввімкнення;
- вольт-амперну характеристику вакуумного діода;
- однопівперіодне випрямлення змінного струму;
- графіки U(t) та I(t);
- модель електронно-променевої трубки;
- керування електронним пучком вертикальними та горизонтальними пластинами;
- тест із 7 запитань.

Для запуску відкрийте `index.html` у браузері.

Рекомендована папка:
`physic/simulations/tema-8/`

- ВАХ наближена до рис. 8.4: за зворотного ввімкнення I = 0, за прямого I нелінійно зростає.
- Випрямлення синхронізоване: полярність, рух електронів, статус, маркер та графіки працюють від однієї фази.
