- модель хаотичного руху та напрямленого дрейфу електронів;
- розрахунок швидкості дрейфу `v = I/(n|e|S)`;
- графік температурної залежності опору металів;
- розрахунок сили струму при зміні температури;
- модель надпровідного переходу;
- шість контрольних запитань.
