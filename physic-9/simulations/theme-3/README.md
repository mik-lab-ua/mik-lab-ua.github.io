# Physics Lab UA — §3

Інтерактивна лабораторія до теми:
«Магнітне поле струму. Правило свердлика».

Реалізовано:
- правило свердлика;
- напрям магнітних ліній для струму ⊙ та ⊗;
- концентричні лінії поля прямого провідника;
- залежність умовного B від сили струму;
- залежність умовного B від відстані;
- порівняння B1 та B2 у двох точках;
- вектор B по дотичній до магнітної лінії;
- модель котушки зі струмом;
- визначення полюсів N і S;
- зміна полюсів при зміні напряму струму;
- вплив сили струму та кількості витків на умовну силу поля;
- тест із 9 запитань.

Для запуску відкрийте index.html.
