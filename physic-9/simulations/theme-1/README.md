# Physics Lab UA — Магнітні явища. Дослід Ерстеда. Магнітне поле

Інтерактивна лабораторія до теми:
«§ 1. Магнітні явища. Дослід Ерстеда. Магнітне поле».

Реалізовано:
- властивості постійних магнітів;
- взаємодія однойменних і різнойменних полюсів;
- залежність сили взаємодії від відстані;
- точка Кюрі для заліза, кобальту та нікелю;
- модель досліду Ерстеда;
- відхилення магнітної стрілки при проходженні струму;
- зміна напряму струму;
- досліди Ампера з двома паралельними провідниками;
- притягання при однаковому напрямку струмів;
- відштовхування при протилежних напрямках струмів;
- магнітне поле навколо прямого провідника;
- напрям ліній поля для струму ⊙ та ⊗;
- тест із 8 запитань.

Файли:
- index.html
- style.css
- app.js
- README.md

Для запуску відкрийте index.html.
