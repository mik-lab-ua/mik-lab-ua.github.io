# Physics Lab UA — §2

Інтерактив до теми «Індукція магнітного поля. Лінії магнітної індукції. Магнітне поле Землі».

Реалізовано:
- вектор магнітної індукції B та одиниця тесла;
- магнітна стрілка як індикатор напряму B;
- переміщення стрілки в полі штабового магніту;
- лінії магнітної індукції та їх напрям N → S зовні магніту;
- зміна умовної густини ліній зі зміною сили поля;
- однорідне поле, позначення ⊙ та ⊗;
- поле між різнойменними полюсами;
- модель магнітного поля Землі, нахил магнітної осі;
- південний магнітний полюс поблизу географічної Півночі;
- модель магнітного збурення/бурі;
- тест із 10 запитань.

Відкрити `index.html` у браузері.
