# Physics Lab UA — §3

Інтерактивна лабораторія до теми «Робота і потужність електричного струму. Закон Джоуля—Ленца».

## Можливості

- вибір побутового електроприладу;
- регулювання напруги, часу роботи та тарифу;
- розрахунок потужності, струму, роботи, енергії у кВт·год і вартості;
- анімований лічильник електроенергії;
- дослід із нагріванням провідника за законом Джоуля—Ленца;
- регулювання сили струму, опору й часу;
- шість контрольних запитань.
