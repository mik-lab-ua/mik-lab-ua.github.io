# Physics Lab UA — §2

Автономна інтерактивна лабораторія до теми «Послідовне і паралельне з’єднання провідників. Шунти і додаткові опори».

## Можливості

- перемикання між послідовною і паралельною схемами;
- регулювання напруги джерела та опорів R1 і R2;
- замикання та розмикання ключа;
- автоматичний розрахунок загального опору, струмів і напруг;
- наочна перевірка співвідношень для обох типів з’єднання;
- калькулятор шунта для амперметра;
- калькулятор додаткового опору для вольтметра;
- шість контрольних запитань.

## Запуск

Відкрийте `index.html` у сучасному браузері. Підключення до інтернету не потрібне.
