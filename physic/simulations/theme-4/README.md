# Physics Lab UA — §4

Інтерактивна лабораторія до теми «Електрорушійна сила. Закон Ома для повного кола».

## Можливості

- регулювання ЕРС, зовнішнього і внутрішнього опорів;
- обчислення сили струму та напруги на клемах;
- розрахунок корисної потужності, внутрішніх втрат і ККД;
- безпечна програмна демонстрація короткого замикання;
- послідовне та паралельне з’єднання однакових джерел;
- тест із шести запитань.
